# Style Matching Engine

## 1. 目标

从 `styles/` 中为当前照片选出最合适的风格候选，避免机械套用固定滤镜。

- 规则冲突时以 `rules/photography-rules.md` 为准，它是唯一总规则源。
- 候选只能来自 `styles/`。Dodge & Burn 等属于 techniques，不是 styles，不参与风格评分。

## 2. 评分

### 2.1 六维评分

对每个候选风格，在以下六个维度上各打 0–5 分：

| 维度 | 权重 | 评价内容 |
|---|---|---|
| Subject | 0.25 | 风格与照片主体的契合度 |
| Light | 0.20 | 风格与原始光线的兼容度 |
| Color | 0.15 | 风格与原始色彩基础的契合度 |
| Narrative | 0.15 | 风格与画面叙事、情绪的一致度 |
| Texture | 0.10 | 风格与画面质感、细节的契合度 |
| Preservation | 0.15 | 套用该风格后原始事实的保留程度 |

### 2.2 总分计算

总分 = Σ（维度得分 × 权重）。六项权重之和为 1，因此总分即加权平均，取值范围为 0–5。

总分保留一位小数，再对照第 3 节的总分带判定。

## 3. 总分带

| 总分 | 判定 | 处理方式 |
|---|---|---|
| >= 4.0 | 强匹配 | 按正常强度调用 |
| 3.2–3.9 | 中匹配 | 可调用，但须降低强度 |
| 2.5–3.1 | 弱匹配 | 仅当用户明确指定该风格时才考虑 |
| < 2.5 | 拒绝 | 不得调用 |

## 4. 选择流程

1. 对 `styles/` 中的每个候选完成六维评分，计算总分并判定总分带。
2. 用户已明确指定风格时：按该风格所在总分带处理。若落在 < 2.5，则拒绝调用。
3. 用户未指定风格时：只在 >= 3.2 的候选中选择。若没有任何候选达到 3.2，调用 `natural_native_professional` 作为自然原生兜底。
4. 若最高总分带中只有一个候选，直接选它。若同一总分带内有多个候选，视为分数接近，按第 5 节的优先级依次比较，直到分出先后。

## 5. 同带候选的优先级

按以下顺序逐项比较。前一项分出先后即停止，前一项相同才看下一项：

1. 对原始事实的改动最少（优先比较 Preservation 得分）；
2. 与原始光线最兼容（优先比较 Light 得分）；
3. 最能突出真实主体（优先比较 Subject 得分）；
4. 所需 techniques 数量最少；
5. 风险最低（以 `rules/photography-rules.md` 为判定依据）。
