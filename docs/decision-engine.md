# Decision Engine

本文件定义后期决策流程。总规则以 `rules/photography-rules.md` 为唯一来源，本文件与其冲突时以总规则为准。

术语约定：
- **风格（styles）**：整体调性方案，参与六维评分与匹配。
- **技术（techniques）**：局部或专项处理手段，如 Portrait Light Sculpting、Dodge & Burn、Slow Shutter。技术不属于风格，不参与风格评分。

## 1. 决策流程：五个问题

按顺序回答以下问题。每一步的结论都是下一步的输入。

1. **主体识别**：这张照片真正的视觉主体是谁或是什么？从第 2 节中选定一个主体类别。
2. **光线判定**：原始光线是什么方向和性质？结论用于第 5 节的门控判定。
3. **问题诊断**：原图最需要解决的问题是什么？例如曝光、白平衡、动态范围、色彩或纹理。
4. **风格选择**：哪种风格最能服务主体，同时不破坏画面事实？按第 3 节评分，按第 4 节决定是否兜底。
5. **技术选择**：哪些摄影技术确有必要？只调用能解决第 3 步所诊断问题的技术，并按第 5、6 节检查门控与冲突。

## 2. 主体类别（Subject classes）

- Landscape
- Snow Landscape
- Wildlife
- Architecture
- Urban
- Documentary Humanistic
- Travel Portrait
- Close Portrait
- Food
- Still Life
- Mixed Scene

## 3. 风格评分与匹配

### 3.1 六维评分权重

| 维度 | 权重 |
|---|---|
| Subject | 0.25 |
| Light | 0.20 |
| Color | 0.15 |
| Narrative | 0.15 |
| Texture | 0.10 |
| Preservation | 0.15 |

### 3.2 总分带

| 总分 | 判定 | 处理 |
|---|---|---|
| >= 4.0 | 强匹配 | 可正常应用该风格 |
| 3.2–3.9 | 中匹配 | 可应用，但降低强度 |
| 2.5–3.1 | 弱匹配 | 仅在用户明确指定该风格时考虑 |
| < 2.5 | 拒绝 | 不应用 |

## 4. 自然原生兜底（natural_native_professional）

**触发条件**：用户未指定风格，且所有候选风格的总分均未达到 3.2。满足条件时，执行以下流程：

1. 修正曝光
2. 修正白平衡
3. 恢复动态范围
4. 调整局部明暗
5. 控制颜色
6. 恢复真实纹理
7. 轻微降噪与锐化
8. 保持自然摄影感

## 5. 技术门控：Portrait Light Sculpting

按第 1 节第 2 步得到的光线判定结论，确定是否调用以及强度：

| 原始光线 | 处理 |
|---|---|
| 明确的单侧光或侧逆光 | 强度 50–80 |
| 柔和侧光 | 强度 20–45 |
| 平光或正面均匀光 | 强度 0–20，仅做局部明度塑造 |
| 背光 | 只强化现有逆光结构，不改成侧光 |
| 光向冲突 | 不调用 |

## 6. 技术冲突规则

**规则**：两项技术试图改变同一视觉变量时，只保留主技术。主技术是直接负责该视觉变量的技术。次技术只能作用于不与主技术重叠的范围；无法做到时，不调用次技术。

**示例**：

- **Portrait Light Sculpting 与强 Dodge & Burn 同时塑造脸部**：以 Portrait Light Sculpting 为主技术。Dodge & Burn 只用于补充材质和局部细节，不参与脸部明暗塑形。
- **Slow Shutter 与全局运动模糊冲突**：只允许场景中真实移动的元素产生运动轨迹，建筑和主体必须保持稳定。
