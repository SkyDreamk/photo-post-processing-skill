# 风格选择决策


人物特写且具有明确侧光、侧逆光或方向性自然光，可考虑人物特写伦勃朗硬光低饱和纪实。
柔和自然光人物照降低该风格优先级。
平光或证件照式光线通常不适合该风格。
城市人物可在旅行人像、城市街拍 Dodge & Burn、银翼杀手2049和伦勃朗人物特写之间比较匹配度。


## 复古电影｜自然光胶片体积感

适用于自然风光、旅行、人文、建筑和具有真实方向性自然光的场景。

若原图具有侧光、侧逆光、逆光、结构明显的云层和较强空间纵深，则提高该风格匹配度。

若原图光线平淡，则以胶片色彩、明暗层次和高光滚降为主，降低体积光强度。

若原图不存在支持条件，禁止强行生成明显光柱、丁达尔效应、夕阳或其他电影特效。


## 侘寂深灰｜低曝光暖色克制纪实

高匹配：建筑、室内、古镇、日式空间、木质空间、静物、生活方式、人文街景、低饱和环境。

中匹配：普通城市环境、自然光较平但材质和空间关系较强的照片。

低匹配：大晴天高饱和风光、野生动物、食品商业摄影，以及已经具有强烈彩色风格的照片。

选择该风格时，应优先保护真实材质和原始光线，不得把侘寂理解为简单的黑灰滤镜。
