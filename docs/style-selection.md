# 风格选择决策

> **本文件定位**
>
> - 总规则以 rules/photography-rules.md 为唯一来源。风格选择按 SKILL.md §3 的六维加权评分与 docs/decision-engine.md 执行。
> - 本文件只补充个别风格的匹配依据，不是独立的选风格标准。与上述文件冲突时，以上述文件为准。

## 通用口径（引用，不在此重新定义）

**六维权重**

| 维度 | 权重 |
|---|---|
| Subject | 0.25 |
| Light | 0.20 |
| Color | 0.15 |
| Narrative | 0.15 |
| Texture | 0.10 |
| Preservation | 0.15 |

**总分带**

| 总分 | 判定 | 处理 |
|---|---|---|
| ≥4.0 | 强匹配 | 可选用 |
| 3.2–3.9 | 中匹配 | 可选用，降强度 |
| 2.5–3.1 | 弱匹配 | 仅在用户明确指定该风格时考虑 |
| <2.5 | 拒绝 | 不得选用 |

**兜底规则**：用户未指定风格时，如果没有任何候选达到 3.2，则使用 natural_native_professional（自然原生）兜底。

**风格与技术的区分**：Dodge & Burn 是 techniques/dodge_burn.md 中的可复用技术，不是风格。

- 不得把它作为风格候选，也不得与风格并列比较。
- 先选定风格，再按技术匹配规则与冲突规则判断是否调用。

**本文件中匹配措辞的含义**：下文的"提高 / 降低匹配度"只说明在六维评分中应作为加分或减分依据的图像条件，不另设分值。最终取舍以总分带为准。

## 人物特写｜伦勃朗硬光低饱和纪实

**前置条件**：主体为人物特写。

**提高匹配度**：原图有明确的侧光、侧逆光或方向性自然光。在 Light 维度作为加分依据。

**降低匹配度**：原图为柔和自然光的人物照。

**通常不适合**：平光，或证件照式正面均匀光。在 Light 维度按不匹配评分。

**候选比较**：城市人物照片应同时把以下三种风格列为候选，按六维加权评分比较，取总分最高者：

- 旅行人像纪实
- 银翼杀手2049
- 人物特写｜伦勃朗硬光低饱和纪实

---

## 复古电影｜自然光胶片体积感

**适用场景**：自然风光、旅行、人文、建筑，以及具有真实方向性自然光的场景。

**提高匹配度**：原图具备以下任一条件时，作为加分依据，具备越多匹配度越高。

- 侧光、侧逆光或逆光
- 结构明显的云层
- 较强的空间纵深

**原图光线平淡时**：

- 下调体积光强度；
- 处理重点改为胶片色彩、明暗层次和高光滚降。

**红线**：原图不具备上述任一条件时，禁止强行生成明显光柱、丁达尔效应、夕阳或其他电影特效。

---

## 侘寂深灰｜低曝光暖色克制纪实

**场景匹配参考**：以下分级用于六维评分时的依据，最终判定以总分带为准。

| 匹配倾向 | 场景 |
|---|---|
| 高 | 建筑、室内、古镇、日式空间、木质空间、静物、生活方式、人文街景、低饱和环境 |
| 中 | 普通城市环境；自然光较平，但材质和空间关系较强的照片 |
| 低 | 大晴天高饱和风光、野生动物、食品商业摄影，以及已具有强烈彩色风格的照片 |

**执行约束**：

- 选用该风格时，优先保护真实材质和原始光线（对应 Texture 与 Preservation 维度）。
- 不得把侘寂当作简单的黑灰滤镜处理。
