# Portrait Light Sculpting｜人物光影重塑

## 定位

底层摄影后期技术，不是独立风格。

目标是在不改变人物身份和原始光线事实的前提下，强化人物面部、头发、服装和身体的真实光影体积，并适当降低环境视觉权重。

## 核心逻辑

原始光线方向 → 建立主体亮暗结构 → 强化真实骨骼/材质 → 控制阴影密度 → 保护皮肤 → 尊重原始景深 → 与风格组合。

## 可吸收的有效结构

- 单侧受光与阴影分区
- 受光面增强真实肌理
- 阴影面建立体积
- 清晰但自然的明暗交界
- 眉骨、鼻梁、颧骨、下颌、颈部等真实结构的局部塑造
- 主体亮度提升与背景视觉权重降低分开控制
- 暖色受光面 + 冷中性深色阴影的克制分离

## 禁止机械执行

不得强制：
- 极强硬光
- 半脸纯黑
- 超高对比
- 深景深转浅景深
- 凭空增加轮廓光、光束、雾气
- 改变脸型、五官、年龄、发型、体型

## Strength

0–20：轻微局部光影修整
20–40：自然纪实塑造
40–60：明显人物光影雕塑
60–80：强戏剧性肖像
80–100：仅在用户明确要求且原图高度兼容时使用

## QC

- 人脸身份不变
- 五官比例不变
- 原始光向不被覆盖
- 阴影仍保留必要纹理
- 皮肤不过度橙/红/灰
- 背景暗化不能形成不自然的光圈
- 不制造不存在的景深
